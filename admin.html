Conectar con GitHub

El panel guarda tus cambios directo en tu repositorio. Necesitas una llave de acceso (token) que se crea una sola vez:

  1. En GitHub: tu foto → Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token.
  2. En Repository access elige Only select repositories y marca tu repositorio del catálogo.
  3. En Permissions → Repository permissions → Contents elige Read and write.
  4. Genera el token, cópialo y pégalo aquí abajo.

El token se guarda solo en este navegador. No lo compartas: quien lo tenga puede editar tu catálogo.

    Sesión

    Activa el contador de visitas

    El conteo lo hace GoatCounter, un servicio gratuito que no usa cookies. Se configura una sola vez:

    1. Crea una cuenta en goatcounter.com. El "Code" que elijas (por ejemplo raxtrude) queda como tu dirección: raxtrude.goatcounter.com.
    2. Ya dentro, entra a Settings y activa Allow adding visitor counts on your website. Sin esto el panel no puede leer los números.
    3. Vuelve aquí, abre Categorías y datos, escribe tu código en el campo de GoatCounter y presiona Publicar cambios.
